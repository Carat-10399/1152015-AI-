## 5. 個人心得
初次體驗ComfyUI真的被它難到了。加上電腦只能跑CPU，導致每生成一張圖就要等好幾個小時，非常考驗耐心。
實際操作時，畫面上一直跳出偵測到錯誤，我完全看不懂、也不知道該怎麼改，卡在電腦前非常苦惱，幸好最後去請教同學才順利解決。後來也慢慢摸索出竅門，發現提示詞用英文比中文精準。
這次的實作讓我大開眼界，原來AI做圖不只是表面上打打字那麼簡單，背後的提示詞、步驟數和各個參數都要配合。雖然過程遇到很多挑戰，但看到最後成品出來，真的非常有成就感！
